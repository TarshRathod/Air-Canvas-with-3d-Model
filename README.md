# Air-Canvas-with-3d-Model

Air Canvas is an interactive system that allows users to draw on the screen without physically touching it or using a mouse. It uses a camera to track hand movements and gestures in real time, converting them into digital strokes on the screen.

The application leverages computer vision techniques to detect and follow the user's hand, enabling a smooth and natural drawing experience in the air. In addition to drawing, it also supports interaction with 3D models, allowing users to control, rotate, and manipulate objects using gestures.

This project is built using React for the frontend. It uses MediaPipe for accurate hand tracking and gesture detection, and integrates Three.js with React Three Fiber to render and control interactive 3D models.

Overall, the project demonstrates the integration of gesture recognition, real-time tracking, and 3D interaction to create a modern, touchless, and intuitive user interface.
